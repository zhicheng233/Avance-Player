# Avance Player

## Current state and entrypoints
- This is a single-project C# Avalonia desktop app. `Program.cs` configures the desktop lifetime; `App.axaml.cs` creates `MainWindow`; `MainWindow.axaml` hosts the navigation shell, the floating playback console, its three popovers (queue / sound / more), and typed page templates; `Views/ImmersiveLyricsView.axaml` is the full-window lyrics experience; `Views/FloatingLyricsWindow.axaml` is the separate always-on-top mini lyric window.
- `ViewModels/MainWindowViewModel.cs` owns navigation, the playback rules (queue, shuffle history, repeat scope, A–B loop, sleep timer, speed), bilingual UI text, the immersive lyrics mode, lyric-file import, local-folder import into a playlist, state restore/save orchestration, and the UI playback clock. `Models/` contains sample music (including a demo `BitrateKbps` used to derive the local quality tier), playlists, lyric lines/words, and parsed `LyricsDocument` metadata. `Services/` provides English/Chinese strings, derives a warm, Monet-inspired palette from the demo artwork color seed (not image-pixel extraction; purple hues are deliberately remapped), contains the lyric parser stack under `Services/Lyrics/`, scans local folders in `Services/LocalFolderScanner.cs`, and now contains the playback and persistence layers.
- Playback is real for imported local files and remains simulated for the built-in demo tracks. `PlayerServices` is the composition root; `Services/Playback/PlaybackService` owns the current session and composes a `SwitchableAudioBackend` that routes absolute paths to `LibVlcAudioBackend` (LibVLCSharp + native libvlc) and relative demo paths to `SimulatedAudioBackend`. Queue/repeat/shuffle/A–B/sleep-timer rules stay in the view model. Backend events are marshalled to the UI thread and filtered by a globally unique playback session id. The 100 ms UI timer polls `PlaybackService.Snapshot`; backend-driven position updates must not call `Seek` (user drags, lyric jumps, and A–B wraps do).
- Persistence lives in `Services/Persistence/`: `PlayerState` + `JsonPlayerStateStore` write `<LocalApplicationData>/AvancePlayer/state.json` atomically (with a `.bak` copy), `DebouncedStateSaver` coalesces frequent updates, and `LibraryRestorer` reloads tags/artwork/lyrics for saved absolute paths while mapping demo relative paths back to the built-in tracks. The state stores library paths, playlist names/order, manual lyric-file paths, volume, last non-zero volume, shuffle, repeat mode, speed index, EQ preset, language, floating-lyrics visibility, and the last track/position. Restore never autoplays; playback starts from the saved position on the first user play. Imported tracks are added to both the library and the target playlist so they survive restart. The equalizer remains a UI demo.
- Local folder import and playback are the real library services: the playlist detail page's "Add local folder" button opens `StorageProvider.OpenFolderPickerAsync`, scans the selected tree recursively off the UI thread, deduplicates by file path, and appends tracks to the open playlist. `LocalFolderScanner` reads tags/duration/bitrate and embedded artwork through TagLibSharp, pairs sidecar covers (`cover`/`folder`/`front`/`album`/`artwork`, then the first image) and lyric files in the audio file's folder, and falls back to a lone lyric file only when the folder contains a single audio file. Supported audio extensions are MP3, FLAC, M4A, AAC, WAV, OGG, Opus, WMA, APE, ALAC, AIFF, DSF, DFF, and MKA. Sidecar lyric matching is case-insensitive so Windows-copied `.LRC` files work on Linux. `LoadTracksAsync` restores a known path list in order without re-scanning unrelated files; it shares the same `LyricsService` through `PlayerServices`.
- Song rows in the library/collection/playlist lists play on double-click; the per-row play button remains a single-click shortcut. The row background is an alpha-zero brush so the whole row is hit-testable, and the tap handler ignores taps that originate inside row buttons while also accepting native `DoubleTapped` gestures (with a duplicate-play guard), so playback does not depend on platform double-click counts. Apply hover transforms to the inner row content, not the row `Border`, so the pointerover hit area stays fixed; the same rule applies to category/playlist cards and lyric lines, whose Fluent template hover/pressed wash is explicitly suppressed.
- Animated backgrounds use an alpha-zero version of the target colour (for example `#001E1D19`) rather than `Transparent`: Avalonia's brush transition interpolates the RGB channels, and `Transparent` is white with zero alpha, which can flash light grey during a fade.
- Custom-drawn controls live in `Controls/`: `WaveProgressBar` (wavy seek bar plus the flat volume variant and A–B range markers), `FluidBackdrop` (soft animated colour field for the lyrics page), `TransportGlyph` (play/pause), `MediaGlyph` (skip, play, shuffle, repeat/repeat-one, queue, more, lyrics, plus/minus, close, fullscreen), `OptionGlyph` (menu sliders/speed/loop/clock), `VolumeGlyph` (monochrome speaker), and `LyricLineTextBlock` (word-by-word lyric runs). Prefer extending these over adding emoji glyphs or platform theme overrides.
- Motion is lightweight and timer-driven: a 33 ms ambient timer advances `AmbientPhase` for the fluid backdrop and wave; the 100 ms UI playback timer polls the active backend (the simulated demo backend advances on its own 50 ms clock); page navigation and now-playing track changes use `FadeSlidePageTransition` (fade plus a small rise/scale), the floating lyric line uses the same transition with a smaller offset, and popovers fade/rise/scale over ~200 ms. Hover states use `RenderTransform` transitions for lift/press feedback, the wave seek bar eases its fill and grows/shrinks the ripple and thumb halo through a small 16 ms motion timer, and glyph state flips pop. Lyric lines transition opacity/background/font size, the lyric list eases to the active line over 460 ms, and the immersive lyrics view plays a staged entrance (`Views/ImmersiveLyricsView.axaml.cs` + `Controls/Motion.cs`). Fullscreen changes still appear instantly. One-shot transform motion animates `Visual.RenderTransform` through a custom `ITransform` interpolator registered in `Controls/Motion.cs`; do not animate `TranslateTransform`/`ScaleTransform` children directly, because Avalonia's built-in transform animator only accepts a `Visual`.
- Lyric centring uses dynamic top/bottom margin on the `LyricsList` items panel (`MainWindow.axaml.cs`): a `ScrollViewer` offset clamps at zero/max, so the first and last lines need half a viewport of padding to reach the centre. Recompute the padding after resize, current-line changes, and imports; keep the nested background dispatcher posts so layout settles before measuring.
- Word-by-word lyrics are driven by `LyricLine.Words` + `CurrentWordIndex`; `LyricLineTextBlock` subscribes to those property changes and recolours `Run`s instead of rebuilding the visual tree every 100 ms tick. Keep `LyricLine.Text` equal to the concatenation of its words for the floating-window fallback and accessibility.
- `Avance-Player.csproj` targets `net10.0` and references Avalonia 12.1.4 (Fluent theme, Inter font), TagLibSharp 2.3.0 for local metadata and embedded artwork, and LibVLCSharp 3.10.2 for local playback. LibVLCSharp is only a binding; a native libvlc runtime must be installed separately on each platform. Keep simulated demo playback clearly separated from the real folder-scanning/lyrics/audio services.

## Build and verification
- .NET SDK 10.0.402 is installed under `~/.dotnet`, but `/usr/bin/dotnet` resolves to a separate SDK 9 installation. Use `~/.dotnet/dotnet build Avance-Player.slnx` (or put `~/.dotnet` first on `PATH`); run with `~/.dotnet/dotnet run --project Avance-Player.csproj` in a desktop session.
- There are currently no tests, lint scripts, CI workflows, or pinned SDK in this repo. Do not lower `net10.0` to work around the system `dotnet` path selecting SDK 9.
- Local playback requires native libvlc. On Linux install the system libvlc package (the development machine has it); on Windows/macOS ship or install the matching LibVLC runtime. `LibVlcRuntime` fails gracefully when initialization is unavailable, and local-file playback reports a bilingual error instead of crashing.
- Offscreen UI checks: an Avalonia.Headless + Skia harness outside the repo (`/tmp/opencode/avance-preview`) renders the main window, popovers, lyrics page, compact width, and floating lyrics window to PNGs. It references the project and must be rebuilt (`~/.dotnet/dotnet build`, then `~/.dotnet/dotnet run --no-build`) after UI changes. Use it instead of desktop screenshots on Wayland/Xwayland sessions. A smaller harness (`/tmp/opencode/lyrics-ui-check`) reports first/middle/last lyric centring, word run colours, and imported TTML frames. `/tmp/opencode/folder-scan-check` builds synthetic nested folders (WAV/MP3, cover images, LRC sidecars) and checks recursive scanning, metadata, artwork, and lyric attachment; `/tmp/opencode/folder-ui-check` drives the view-model import path and renders the playlist state. `/tmp/opencode/backend-check` exercises LibVLC (using `--aout=dummy`), simulated playback, JSON state, library restore, and the view-model playback/restore clock; it needs a small WAV argument.
- Parser fixtures: the AMLL TTML database (`https://github.com/amll-dev/amll-ttml-db`) is useful for real TTML/QRC/YRC/LYS/LRC samples, but its lyric text is copyrighted. Use it for local inspection only; commit synthetic fixtures, not downloaded songs. The parser smoke harness lives at `/tmp/opencode/lyrics-check`.
- Localization check: every `Text[Key]`/`Text.Format("Key", …)`/`SetStatus("Key", …)` key in XAML and C# must exist in both dictionaries in `Services/LocalizedText.cs`; a quick scripted diff between XAML keys and the two dictionary blocks is the fastest guard.

## Product scope and remaining work
- The prototype demonstrates OOP music/playlist models, library browsing, playlist edits, playback controls/history, bilingual UI (English/Chinese), artwork-seeded theme colors, a floating playback console with queue, quality/EQ/speed, A–B loop, sleep timer, play order, loop scope, volume and floating lyrics, a full-window synchronized lyrics view with manual lyric import, and recursive local-folder import with tags, covers, and sidecar lyrics. Local import, local playback, and state persistence are real; built-in demo tracks still use the simulated backend. The remaining production gaps are equalizer processing, packaging the native libvlc runtime, and broader codec/device testing.
- Lyric support: TTML (Apple/AMLL word timing, inline `x-translation`/`x-roman`/`x-bg`, metadata translation tables), LYS, QRC (plain/decrypted), KRC (plain and XOR+zlib encrypted), YRC, LRC/ESLRC (including enhanced `<mm:ss.xx>` word tags and `offset`), ASS/SSA (karaoke `\k`/`\kf`/`\ko`, translation/romaji dialogue pairing), and SRT. Plain LRC/SRT are line-level by nature. Encrypted QQ Music QRC is detected and rejected with a clear message rather than decoded. Text encoding detection tries BOM, strict UTF-8, then GB18030 and Shift-JIS (the kana count decides when both decode).
- Demo-only boundaries: audio quality and equalizer bands remain UI-only. The quality chip is a read-only "bitrate · tier" label derived from demo metadata or TagLib's reported bitrate, not a decoded audio probe. Playback speed, volume, sleep timer, play/pause, stop, seek, and A–B loop are real for local files and simulated for demo tracks; the settings panel still labels the equalizer/quality area as a demo. Two demo tracks get synthetic, evenly distributed word timings solely to exercise the word renderer; imported files replace them. Keep that honesty when extending the prototype.
- Keep the Material + island-inspired Avalonia UI, fluid ambient background, and animated lyric highlighting; do not copy reference-image assets or introduce Windows-only WPF APIs.
- The bilingual toggle depends on `LocalizedText` raising `"Item"` (Avalonia indexer bindings) as well as `"Item[]"`; keep both when changing the notification plumbing. Avoid setting `Opacity` on containers whose text must stay legible (it fades children too); use an ARGB background instead.
- `TextBlock` clips glyphs to its own bounds. A custom `LineHeight` can leave the last line's descenders outside those bounds (the English hero headline did); set `ClipToBounds="False"` on such a block rather than removing the tight line spacing.

## C# style and design references
- Follow this repo's file-scoped namespaces and same-line opening braces for new code. The author's other projects do **not** share one brace convention (`WhereMyWinCursor` uses same-line; `PN532-Aime-Reader` uses next-line); favor local consistency over assuming a global style.
- For substantive work, consult the author's C# code at https://github.com/zhicheng233: `WhereMyWinCursor` separates typed config/persistence and XAML/ViewModel UI state; `PN532-Aime-Reader` isolates device I/O behind an interface with a replay implementation. Keep library/playback logic out of Avalonia window code-behind and isolate the eventual audio backend; do not import Windows-only WPF APIs.
